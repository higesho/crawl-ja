Dungeon Crawl Stone Soup 0.34.1 日本語版(タイル版 / Windows 64bit)
=====================================================================

Dungeon Crawl Stone Soup(DCSS)の 0.34.1 を日本語で遊べるようにしたものです。
本家の配布物ではありません。日本語版についての問い合わせを本家に送らないよう
お願いします。


■ 起動のしかた

zip を好きな場所に展開して、crawl.exe を起動してください。インストールは
いりません。初回から日本語で始まります。

セーブデータとキャラクターの記録は、展開したフォルダの中の saves と morgue に
できます。フォルダごと別の場所に移しても続きから遊べます。

Windows のセキュリティ警告(SmartScreen)が出たら、「詳細情報」から実行して
ください。署名のない個人のビルドなので出ることがあります。


■ 設定

設定ファイルは settings\init.txt です。先頭に日本語版の設定があります。

  language = ja           ゲームを日本語で表示する
  tile_font_*_file = ...  タイル版のフォント(BIZ UDゴシック)

英語で遊びたいときは language の行の先頭に # を付けてください。
BIZ UDゴシックは Windows 10(2018年10月の更新以降)と Windows 11 に標準で
入っています。入っていない環境では、ほかの日本語のフォント(例えばメイリオの
C:/Windows/Fonts/meiryo.ttc)に書き換えてください。

自分用の設定を書くときは、settings\init.txt を直接書き換えるより、crawl.exe と
同じフォルダに init.txt を作るほうが更新のときに楽です。その場合は日本語版の
設定の行もそちらに書き写してください(init.txt があると settings\init.txt は
読まれません)。


■ 遊び方の説明

ゲーム中に ? を押すとヘルプが出ます。マニュアル、クイックスタート、
オプションの説明、適性表なども日本語にしてあります。初めての人は、最初の
メニューからチュートリアルを選ぶのがおすすめです。


■ 本家版との違い

ゲームの中身は本家の 0.34.1(安定版ブランチの 2026年6月までの修正を含む)と
同じです。変えたのは表示の日本語化と、日本語を表示するための修正だけです。

英語のまま残っているもの:
  ・本や詩から採った引用文の一部
  ・デバッグ用の表示と、ウィザードモードの一部
  ・アイテム説明の検索に使う接頭語

メッセージの色分けなどで正規表現を書くオプション(message_colour など)は、
日本語のメッセージに対して照合されます。英語の例はそのままでは効きません。


■ 分かっている問題

  ・ヘルプ文書の一部で、行の長さがそろっていないところがあります。
  ・ゲーム後半の画面は、ウィザードモードで一通り見ただけです。遊んでいて
    英語が出たり、表示が崩れたりしたら知らせてもらえると助かります。
  ・公式版のセーブデータとの行き来は試していません。


■ 謝辞

訳文の多くは、dplusplus さんによる 0.16 と 0.19 の日本語版を土台にしています。
長い時間をかけて訳してくださった方々に感謝します。
