# DCSS 0.34.1 日本語版 ja6

Dungeon Crawl Stone Soup 0.34.1 の日本語版、6 回目のリリースです。ja5 の修正版です。

## ファイル

- `stone_soup-0.34.1-ja6-tiles-win64.zip`:Windows(64bit)用のタイル版です。展開して `crawl.exe` を起動すれば、そのまま日本語で遊べます。
- `stone_soup-0.34.1-ja6-android-arm64.apk`:Android 用(arm64-v8a)です。くわしくは下の「Android 版」を見てください。
- `stone_soup-0.34.1-ja6-src.zip`:ソースコード一式です(ビルドに使うライブラリの contrib も含みます)。

## ja5 からの変更

- ダンジョン全体の品物の検索(Ctrl+F)など、長い一覧でカーソルやマウスを動かしたときにカクつくことがあったのを軽くしました。
- 鍛造術の呪文「稲妻の渦巻の鍛造」と、それで作るものの名前を「稲妻の尖塔の鍛造」「稲妻の尖塔」に改めました。
- Android 版: 縦画面でバーチャルパッドを出しているときは、ゲームの画面を上半分、パッドを下半分に分けて、ボタンで画面が隠れないようにしました。

## Android 版

- **デバッグ鍵で署名した APK** です。Google Play からではなく、APK を直接入れる形になります。端末の設定で「提供元不明のアプリ」のインストールを許可してから入れてください。
- 本家の Android 版(`org.develz.crawl`)と同じアプリ ID です。本家版が入っている端末では、先にそちらを削除しないと入りません。削除するとセーブデータも消えるので注意してください。ja2〜ja5 からは、そのまま上書きで入れられます。
- 対応しているのは 64bit の ARM(arm64-v8a)の端末だけです。最近のスマートフォンはほとんどこれです。
- 縦長の画面で出る小さなステータス欄の見出し(AC EV SH など)は英語のままです。

## 注意

- 設定は `settings/init.txt` の先頭にあります(Windows 版)。英語に戻すときは `language = ja` の行をコメントにしてください。
- フォントは Windows 標準の BIZ UDゴシックを使います(Windows 版)。入っていない場合は、`settings/init.txt` のフォントの指定をメイリオなどに変えてください。
- 公式版のセーブデータとの行き来は試していません。
- 英語が出たり表示が崩れたりしたら Issue で教えてください。
