# DCSS 0.34.1 日本語版 ja3

Dungeon Crawl Stone Soup 0.34.1 の日本語版、3 回目のリリースです。Android 版のゲームパッド対応と、パッドで問いに答えやすくする改良です。

## ファイル

- `stone_soup-0.34.1-ja3-tiles-win64.zip`:Windows(64bit)用のタイル版です。展開して `crawl.exe` を起動すれば、そのまま日本語で遊べます。
- `stone_soup-0.34.1-ja3-android-arm64.apk`:Android 用(arm64-v8a)です。くわしくは下の「Android 版」を見てください。
- `stone_soup-0.34.1-ja3-src.zip`:ソースコード一式です(ビルドに使うライブラリの contrib も含みます)。

## ja2 からの変更

### Android 版のゲームパッド

- Bluetooth や USB のゲームパッドが使えるようになりました。操作は Windows 版と同じです。
- 画面に重ねるバーチャルパッドを足しました。起動画面の「バーチャルパッド」をオンにすると出ます。
  - 左スティックで移動、右スティックでカーソル、L3 で左クリック、R3 で右クリックです。
  - A/B/X/Y、LB/RB、LT/RT、Start/Back は Windows 版のパッドと同じ割り当てです。
  - ボタンの外に触れたときは、今までどおり画面の操作になります。
- パッドを使うとき(バーチャルパッドを出すとき、またはパッドを繋いでいるとき)は、画面のキーボードを出しません。文字を入れたいときは、ゲームメニュー(Back)の「画面上のキーボードを表示/非表示にする」で出せます。キーボードを出している間は、バーチャルパッドが隠れます。

### パッドで問いに答える

- メッセージ欄で文字のキーを求めていた問いを、カーソルで選んで A で決められるようにしました。能力値の上昇、キー割り当ての変更(`=`)、カードを選ぶ、Gozag の薬と投資、祖霊の性別、仲間への命令(`t`)です。
- 装備の付け替え、呪文を唱える、品物を選ぶ問いでは、十字で一覧が開きます。
- 「はい/いいえ」の問いがメッセージ欄に出たときは、十字を押すと選べる形に切り替わります。店での購入の確認も、パッドで「はい」を選べます。
- 数を入れる問い(拾う個数など)では、上下で 1 ずつ、斜め(PgUp/PgDn)で 10 ずつ増減できます。旅行先の階を訊く問いでは、上下で浅い階・深い階へ動きます。

### 訳の直し

- 一部の文で「\n」がそのまま表示されていたのを、改行にしました。

## Android 版

- **デバッグ鍵で署名した APK** です。Google Play からではなく、APK を直接入れる形になります。端末の設定で「提供元不明のアプリ」のインストールを許可してから入れてください。
- 本家の Android 版(`org.develz.crawl`)と同じアプリ ID です。本家版が入っている端末では、先にそちらを削除しないと入りません。削除するとセーブデータも消えるので注意してください。ja2 からは、そのまま上書きで入れられます。
- 対応しているのは 64bit の ARM(arm64-v8a)の端末だけです。最近のスマートフォンはほとんどこれです。
- 縦長の画面で出る小さなステータス欄の見出し(AC EV SH など)は英語のままです。

## 注意

- 設定は `settings/init.txt` の先頭にあります(Windows 版)。英語に戻すときは `language = ja` の行をコメントにしてください。
- フォントは Windows 標準の BIZ UDゴシックを使います(Windows 版)。入っていない場合は、`settings/init.txt` のフォントの指定をメイリオなどに変えてください。
- 公式版のセーブデータとの行き来は試していません。
- 英語が出たり表示が崩れたりしたら Issue で教えてください。
