# DCSS 0.34.1 日本語版 ja2

Dungeon Crawl Stone Soup 0.34.1 の日本語版、2 回目のリリースです。訳の直し、ゲームパッド対応、Android 版の追加です。

## ファイル

- `stone_soup-0.34.1-ja2-tiles-win64.zip`:Windows(64bit)用のタイル版です。展開して `crawl.exe` を起動すれば、そのまま日本語で遊べます。
- `stone_soup-0.34.1-ja2-android-arm64.apk`:Android 用(arm64-v8a)です。くわしくは下の「Android 版」を見てください。
- `stone_soup-0.34.1-ja2-src.zip`:ソースコード一式です(ビルドに使うライブラリの contrib も含みます)。

## ja1 からの変更

### 訳の直し

英語版の DCSS wiki を日本語に訳す作業の中で、ゲームの説明文と突き合わせて見つかった誤りや訳し漏れを直しました。

- ルーの称号の 7・8 段目が 1 段ずれていたのを直しました(卓越せる覚者、一滴の水)。
- 説明文の訳し漏れを足しました(燃えさかる死のシミター、耐性の盾、冷たき死の短刀、ランス『ドラゴン殺し』、英雄化、深淵への門の引用など)。
- 古い英文の訳のまま残っていた説明を、今の英文から訳し直しました(Hurl Damnation、閃光のクローク、セクゴブの護符など)。
- 誤訳を直しました(タイタン、ワニガメ、ワイバーン、鉄縛の雷巨人、ジェシカ、ハロルドなど)。
- モンスターの呪文 Blink Range と Blink Away がどちらも「瞬間退避」だったので、Blink Range を「視界内退避」にしました。
- 表記をそろえました(紫色ドラコニアン、シゴツヴィ、強靭な皮膚など)。

### ゲームパッド対応(Windows のタイル版)

本家にはないゲームパッドの操作を足しました。

- 十字キーと左スティックで移動します(メニューではカーソル移動)。斜めは 2 方向を同時に入れます。
- A で決定、B で取消です。
- 右スティックでマウスのカーソルが動き、L3(左スティックの押し込み)で左クリック、R3(右スティックの押し込み)で右クリックになります。地図のマスや所持品の欄を、マウスと同じように選べます。
- ほかのボタンの既定の割り当ては次のとおりです。
  - X 自動探索、Y 自動戦闘
  - LB 階段を下りる、RB 階段を上る
  - LT 所持品、RT 射撃
  - Back ゲームメニュー、Start 呪文を唱える
- LB や RB を押しながらほかのボタンを押す同時押しの組み合わせにも、コマンドを割り当てられます。
- 割り当ては、ゲームメニュー(Back、F1)の「ゲームパッドの割り当て」で、ゲームの中から変えられます。rc ファイルのオプション `pad_bind` でも書けます。割り当てのないボタンは、マクロのキーとして使えます。
- パッドの入力を機械的に流して動きを確かめましたが、実際のパッドではまだ試していません。うまく動かない機種があったら Issue で教えてください。

### マウスのホイールで拡大・縮小(Windows のタイル版)

- ダンジョンの上でマウスのホイールを回すと、表示を拡大・縮小します(Ctrl+= / Ctrl+- と同じです)。階の地図(X)の中でも使えます。

### Android 版

本家の Android 版に日本語化を組み込みました。

- 日本語のフォント(BIZ UDゴシック)を同梱しています。端末のフォントは使いません。
- 起動画面は、端末の言語が日本語なら日本語で出ます。
- 初めて起動したときに作られる設定ファイルで、日本語表示が有効になります。

## Android 版

- **デバッグ鍵で署名した APK** です。Google Play からではなく、APK を直接入れる形になります。端末の設定で「提供元不明のアプリ」のインストールを許可してから入れてください。
- 本家の Android 版(`org.develz.crawl`)と同じアプリ ID です。本家版が入っている端末では、先にそちらを削除しないと入りません。削除するとセーブデータも消えるので注意してください。
- 対応しているのは 64bit の ARM(arm64-v8a)の端末だけです。最近のスマートフォンはほとんどこれです。
- 確かめたのは Android 15 のエミュレータだけです。実機ではまだ試していません。
- 縦長の画面で出る小さなステータス欄の見出し(AC EV SH など)は英語のままです。

## 注意

- 設定は `settings/init.txt` の先頭にあります(Windows 版)。英語に戻すときは `language = ja` の行をコメントにしてください。
- フォントは Windows 標準の BIZ UDゴシックを使います(Windows 版)。入っていない場合は、`settings/init.txt` のフォントの指定をメイリオなどに変えてください。
- 公式版のセーブデータとの行き来は試していません。
- 英語が出たり表示が崩れたりしたら Issue で教えてください。
