# DCSS 0.34.1 日本語版 ja4

Dungeon Crawl Stone Soup 0.34.1 の日本語版、4 回目のリリースです。ゲームパッドだけで遊べる範囲を広げました。

## ファイル

- `stone_soup-0.34.1-ja4-tiles-win64.zip`:Windows(64bit)用のタイル版です。展開して `crawl.exe` を起動すれば、そのまま日本語で遊べます。
- `stone_soup-0.34.1-ja4-android-arm64.apk`:Android 用(arm64-v8a)です。くわしくは下の「Android 版」を見てください。
- `stone_soup-0.34.1-ja4-src.zip`:ソースコード一式です(ビルドに使うライブラリの contrib も含みます)。

## ja3 からの変更

### ゲームパッド

- LB・RB との同時押しに、よく使うコマンドを割り当てました。

| ボタン | LB と同時 | RB と同時 |
|---|---|---|
| X | 休む | 待つ |
| A | 拾う | 扉を閉める |
| B | 置く | メッセージの履歴 |
| Y | 階を指定して旅行 | 能力 |
| LT | 階の地図 | 薬を飲む |
| RT | 見回す | 巻物を読む |
| Start | 呪文を覚える | スキル |
| Back | キャラクター概要 | ダンジョンの概観 |

- LB か RB を押しながら移動すると、走る・その場で攻撃になります。
- 狙い・階の地図・メニューの中では、ボタンに決まった役目があります。
  - 狙い: LB/RB で相手の切り替え、X で説明、RT で撃つ
  - 階の地図: LB/RB で階段を探す、LT/RT で階を替える、X で自分の位置へ
  - メニュー: X で選ぶ・外す、Y で全部選ぶ、LB/RB でページ送り
- 品物や地形の説明で A を押すと、読む・手に持つ・置くなどの操作を選べます。
- 文字を入れる欄では、Y で文字を選ぶ表が開きます(英数字)。X で 1 文字消します。
- 「yes」と打たせる確認や、祭壇で神を捨てる確認にも、パッドで答えられます。
- ヘルプの章、スキルの画面の切り替えと目標値も、パッドで選べます。
- 起動画面で B を押したときは、ゲームを終える前に確かめます。

## Android 版

- **デバッグ鍵で署名した APK** です。Google Play からではなく、APK を直接入れる形になります。端末の設定で「提供元不明のアプリ」のインストールを許可してから入れてください。
- 本家の Android 版(`org.develz.crawl`)と同じアプリ ID です。本家版が入っている端末では、先にそちらを削除しないと入りません。削除するとセーブデータも消えるので注意してください。ja2・ja3 からは、そのまま上書きで入れられます。
- 対応しているのは 64bit の ARM(arm64-v8a)の端末だけです。最近のスマートフォンはほとんどこれです。
- 縦長の画面で出る小さなステータス欄の見出し(AC EV SH など)は英語のままです。

## 注意

- 設定は `settings/init.txt` の先頭にあります(Windows 版)。英語に戻すときは `language = ja` の行をコメントにしてください。
- フォントは Windows 標準の BIZ UDゴシックを使います(Windows 版)。入っていない場合は、`settings/init.txt` のフォントの指定をメイリオなどに変えてください。
- 公式版のセーブデータとの行き来は試していません。
- 英語が出たり表示が崩れたりしたら Issue で教えてください。
