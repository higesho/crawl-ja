# DCSS 0.34.1 日本語版 ja5

Dungeon Crawl Stone Soup 0.34.1 の日本語版、5 回目のリリースです。ゲームの中の選択肢を、パッドのカーソルと決定ボタンで選べるようにしました。

## ファイル

- `stone_soup-0.34.1-ja5-tiles-win64.zip`:Windows(64bit)用のタイル版です。展開して `crawl.exe` を起動すれば、そのまま日本語で遊べます。
- `stone_soup-0.34.1-ja5-android-arm64.apk`:Android 用(arm64-v8a)です。くわしくは下の「Android 版」を見てください。
- `stone_soup-0.34.1-ja5-src.zip`:ソースコード一式です(ビルドに使うライブラリの contrib も含みます)。

## ja4 からの変更

### ゲームパッド

- 品物や地形の説明では、下の行の操作(読む・手に持つ・置くなど)にカーソルが付きます。十字の左右で選んで A で行います。呪文書では呪文も同じ行に並び、選ぶと呪文の説明が出ます。Android でパッドを使っているときも、マウスの右クリックと同じことができます。
- モンスターの説明では、A で呪文を選んで説明を見られます。十字の左右でページを替えます。神の説明も左右でページを替えます。
- メニューでは、X で選ぶ・外す、LT・RT で `!`・`?` です。拾う・置くで 2 個以上ある品物を X で選ぶと個数を訊きます(十字の上下で増減、A で決定)。
- キャラクター概要(`%`)では A で装備を選んで説明を、ダンジョンの概観(Ctrl+O)では A で「階へ旅行する」「店の一覧」などを選べます。
- 新しいゲームで、おまかせの組み合わせを遊ぶか選び直すかの問いと、同じ名前のセーブを上書きする確認を、カーソルで選べます。名前の欄でも Y で文字を選べます。
- ネメレクスの能力「スタック・ファイブ」では、札にカーソルを置いて X で選び、入れ替えます。A で決めます。

## Android 版

- **デバッグ鍵で署名した APK** です。Google Play からではなく、APK を直接入れる形になります。端末の設定で「提供元不明のアプリ」のインストールを許可してから入れてください。
- 本家の Android 版(`org.develz.crawl`)と同じアプリ ID です。本家版が入っている端末では、先にそちらを削除しないと入りません。削除するとセーブデータも消えるので注意してください。ja2〜ja4 からは、そのまま上書きで入れられます。
- 対応しているのは 64bit の ARM(arm64-v8a)の端末だけです。最近のスマートフォンはほとんどこれです。
- 縦長の画面で出る小さなステータス欄の見出し(AC EV SH など)は英語のままです。

## 注意

- 設定は `settings/init.txt` の先頭にあります(Windows 版)。英語に戻すときは `language = ja` の行をコメントにしてください。
- フォントは Windows 標準の BIZ UDゴシックを使います(Windows 版)。入っていない場合は、`settings/init.txt` のフォントの指定をメイリオなどに変えてください。
- 公式版のセーブデータとの行き来は試していません。
- 英語が出たり表示が崩れたりしたら Issue で教えてください。
