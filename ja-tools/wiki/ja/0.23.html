主な変更

  • 罠の仕組みを全面的に見直した。
  • ラビリンスに代わる新しいポータル、試練場が加わった。
  • ネメレクス・ソベーを作り直した。
  • 9つの固定アーティファクトを作り直し、新しい固定アーティファクト「リフト」を加えた。
  • シードを指定したダンジョンでの遊び方に対応した。

分岐・環境

  • 罠を全面的に見直した。
    • 床に生成された罠は、はじめから必ず見えている。
    • 探索中に、床の罠とは関係なく「罠の効果」が起こることがある。起こりうる効果は警報、縦穴、モンスターの近くへのテレポートだ。
    • モンスターが罠を作動させるのは、プレイヤーの視界の中だけになった。
    • 警報の罠は、視界の中で作動すると必ずプレイヤーを標的状態にするようになった。
    • 網の罠は、視界の中で作動するたびにプレイヤーを網にかけようとするようになった。
    • 新しい罠として転送の罠が加わった。作動すると、罠が見える位置にいる者がみなブリンクで飛ばされる。
    • 納骨堂、ゾットの領域:5、太古の霊廟での罠の配置を見直した。ゾットの領域:5 と太古の霊廟からは、網の罠を除く機械仕掛けの罠がすべてなくなった。
    • (足踏みスイッチで作動する)格子の罠はなくなった。
  • ラビリンスに代わる新しいポータル、試練場が加わった。
    • 試練場では、いくつもの闘技場を通る道筋をプレイヤーが選ぶ。どの闘技場にも、(ときに珍しい)モンスターと戦利品がある。
    • 各闘技場へは転送装置で一方通行に進む。テレポートとゴルブリアの通り道の呪文は使えない。
    • どの道を選んでも、最後は出口と財宝の山を守るミノタウロスのもとにたどり着く。
    • 試練場は、以前ラビリンスが生成されていた場所に現れる。
  • シードを指定した遊び方に対応した。
    • 決まったシードをもとに、つながったダンジョン全体を前もって生成しておくオプションが加わった。少し時間がかかるが、同じシードなら何度遊んでも同じダンジョンになることが保証される。
    • このオプションはまだオンラインでは使えないが、オフラインなら使える。くわしくはマニュアルの「Seeded play」の節を参照。
    • この機能のために、ダンジョンの乱数生成器をゲーム進行の乱数生成器から切り離した。
    • ゲームのシードごとに固有のダンジョン(地形、モンスターやアイテムの配置を含む)が生成される。Crawl のバージョンが同じで、階を生成する順番も同じなら、ダンジョンは必ず同じになる。
    • 同じシードの二つのゲームで違うダンジョンが生成されたら、バグとして報告してほしい!
  • 序盤の新しいヴォールトが加わった。テーマのあるアイテムの店や、虎の巻を守るモンスターが出てくる。多くの分岐に、幽霊の出る新しいヴォールトも加わった。
  • 新しいダンジョンの地形が二つ有効になった。一つは迷宮用、一つは獣の棲み処用だ。
  • 閉じていても向こう側が見える半透明の扉が加わった。エルフの大広間の一部の地形と、ルーンで封印された扉のヴォールトの大半を含むいくつかのヴォールトで使われている。

キャラクター

  • 麻痺や石化しているあいだは、プレイヤーが眠らされなくなった。
  • 天狗の永続的な飛行は、XL 5 になるとすぐに使えるようになった。
  • 天狗の EV ボーナスは、装備による EV の上昇分にはかからなくなった。
  • 放浪者の最初の呪文ライブラリが、装備と一緒に知らされるようになった。
  • レベル1の呪文をちょうど一つだけ持って始まる放浪者は、その呪文を記憶した状態で始まる。

神

  • ネメレクス・ソベーを作り直した。
    • デッキはアイテムではなくなり、能力から使うようになった。
    • ネメレクスは「脱出のドロー」「破壊のドロー」「召喚のドロー」の三つの能力を授け、これらでカードの効果を得る。
    • デッキの能力には希少度がない。カードの強さは祈祷のスキルと信仰心だけで決まる。
    • ネメレクスは、三つの抽象的なデッキにときどきカードを足していく。
    • トリプル・ドローはこれまでどおり三つのデッキで使え、三枚のカードから一枚を選べる。消費する信仰心は増えた。
    • ディール・フォーは一つのデッキから四枚のカードを配る。消費する信仰心は減った。
    • スタック・ファイブは、三つのデッキのどれからでもカードを五枚引き、プレイヤーの決めた順に積んでおいて、あとで引けるようにする。新しく積み込むと、前に積んだ山は捨てられる。消費する信仰心は以前のスタック・ファイブと同じだ。
    • 加速のカードは敵を加速させなくなり、代わりに威力に比例した確率で必ず敵を減速させるようになった。
    • 嵐のカードを見直した。突風を起こしたあと、電撃の爆発を1〜9回起こすようになった。
  • エリヴィロンの他者の治癒を調整した。
    • 式は、個々のモンスターの最大 HP ではなく、モンスターの種類だけで決まるようになった。
    • プレイヤーの幽霊とパンデモニウムの君主には効かなくなった。
    • ターゲットの選択画面に、中立化できる確率が表示されるようになった。
  • アシェンザリは、探索中に起こる罠の効果から信者を守るようになった。
  • クァズラルの雲への耐性が、精霊召喚で呼び出した精霊にも及ぶようになった。
  • フェダスがプレイヤーの呪文から植物を守る効果が、視界全体を攻撃する呪文にも及ぶようになった。
  • マクレブの小なる破壊の酸のダメージを下げた。
  • 諸宗派の寺院、深い水脈、溶岩については、探索による信仰心が得られなくなった。
  • ベオ、ゴザーグの分岐の買収、ジーヴァによるモンスターの改宗は、モンスターが視界に入った次のターンではなく、見た瞬間に試みられるようになった。

インターフェース

  • 呪文のダメージを伝えるメッセージの句読点を、近接攻撃のダメージと同じ基準で与えたダメージを表すように調整した。
  • ダメージを与える銘のメッセージの句読点も同じように調整した。
  • 'xv' で見るモンスターの説明に、呪文の射程が表示されるようになった。
  • 信仰の画面 '^' に、追加の情報が必要な神のための4枚目のページが加わった。
    • アシェンザリでは、呪いの装備で縛られている状態についての情報が表示される。
    • ベオでは、名前のある信者の一覧が、贈った品とともに表示される。
    • ゴザーグでは、買収の情報が表示される。
    • ヘプリアクルカナでは、祖霊の強化が表示される。
    • ネメレクス・ソベーでは、デッキの情報が表示される。
    • ウー・ジアンでは、武術の攻撃についての情報が表示される。
  • ヘプリアクルカナの祖霊の HP が満タンになると、休憩が中断されるようになった。この中断のくわしい動きは rest_wait_ancestor で設定できる。
  • 新しい display_chars の cloud_weak、cloud_fading、cloud_terminal で、コンソール版で雲の残り時間がわかるようになった。
  • WebTiles の利用者は「Forgot Password」のリンクから、登録したメールアドレスに届くリンクでパスワードを再設定できるようになった。この機能は、公式サーバーの大半ではまだ有効になっていない。

アイテム

  • 固定アーティファクトの変更:
    • 新しい固定アーティファクト: +8 の悪魔の三叉戟「リフト」{distort, reach+}。間合いが3の歪曲の悪魔の三叉戟で、打擲型の攻撃ができる。
    • 謳う剣の音波のダメージ効果が強くなり、緊迫度が低くても発動するようになった。ただし、攻撃が当たったときにしか発動しない。ヴォーパルの銘もついた。
    • スプリガンのナイフは、どの急所攻撃も眠っている相手への急所攻撃と同じ扱いにするようになった。代わりに Dex+4 と MR+ はなくなった。
    • 不運のローブは +5 {*Contam *Corrode *Drain Harm *Slow EV+5} になり、いつも鑑定済みになった。
    • 苦悩の王笏は +7 の苦痛のイブニングスターになり、その拷問は使い手には効かなくなった。
    • 電弧の刃の効果で放つ空電放射は一回だけになったが、呪文の威力はとても高くなった。武器の強化値は +8 になった。
    • とどめの一撃は Str+3 がなくなり、代わりに相手を一撃で爆散させることがあるようになった。
    • 雲のローブは +3 {+Thunder rCloud rElec} になり、以前の霧の代わりに、発動して嵐の雲を出せるようになった。
    • 嵐の弓は、ときどき雨雲を出すことがなくなった。
    • ズホルの皮に SInv と、常に働く代謝の凍結の効果がついた。
    • 近くの味方を怒らせかねない近接攻撃の効果を持つ固定アーティファクトでは、きちんと警告が出るようになった。
  • 掘削、隷属、火炎、金縛り、変化、でたらめな効果のワンドの充填数を減らした。
  • 死体を解体すると、必ず骸骨が残るようになった。
  • 吹き矢筒のターゲットの選択画面に、相手に効く確率が表示されるようになった。
  • アイテムの検索で、片手持ちか両手持ちかで探せるようになった。

Lua

  • clua と dlua で使われていた独自の `require` は `crawl_require` という名前に変わった。
  • clua からターゲットの選択を使えるように、`spells` モジュールに新しい関数 `spells.path` が加わった。

モンスター

  • モンスターの武器、防具、ワンドは、そのモンスターをはじめて見たときに鑑定され、プレイヤーにわかるようになった。
  • よろめき歩くマングローブの能力絡まる木の根は、「根」の状態を与えるのではなく、打擲型の締めつけを行うようになった。
  • ジョーグルンが絡まる木の根の呪文を覚え、沼にも出るようになった。
  • 殺人ピエロはパイを投げる能力を持つようになった。パイはプレイヤーにダメージを与え、酩酊、静寂、薬×、能力値の低下、rF-、コウモリ・豚・霧への変身を伴う変化のどれか一つを与える。
  • 殺人ピエロは、ピエロ特有の近接攻撃の追加効果の代わりに、強化値の高い銘入りの棍棒を持つようになった。速い再生もなくなった。
  • オーブを持っての脱出中に湧くモンスターが、プレイヤーの近くに出やすくなり、危険にもなった。
  • パンデモニウムの君主の使う呪文と攻撃の追加効果がわかるようになった。
  • 召喚したモンスターが魅了される・魅了が解ける、中立化される、スライム化されるなどして立場が変わると、そのモンスターが呼び出したものは消えるようになった。
  • 混乱しているモンスターも、プレイヤーと同じく 1/3 の確率でふつうに動けるようになった。
  • 巨人のモンスターは蜘蛛の巣を引きちぎれなくなった。

呪文

  • 混乱の一撃は、武器を構えていても使えるようになった。

0.23.1

バグ修正版の 0.23.1 は2019年2月28日にリリースされた。

  • 棒切れの蛇と鼠の毛皮のクロークで生まれた味方をプレイヤーが吸血の攻撃で攻撃しても、HP が回復したり吸血鬼の満腹度が上がったりしなくなった。
  • オゾクブの瞬間凍結のダメージを、本来の量に引き上げた。
  • ユニークのアイズル、白娘子、ドナルド、ジョーグルン、マーラの配置を直し、想定どおりの階の範囲全体に出るようにした。
  • ボリスが再び現れる確率を下げ、以前と同じにした。
  • 黄色のドラコニアンが、XL 7 で rCorr の変異を正しく得るようになった。
  • バグ修正、調整、整理は全部で45件。
