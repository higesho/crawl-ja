Crawl のソースコードとは、コンパイルして遊べるゲームにするための、プログラムの命令とデータ一式のことだ。たいていの商用ソフトと違って、Crawl はオープンソースのライセンス(GPL V2+)で公開されている。つまり、ソースコードは誰でも自由に見られる。Crawl は C++ で書かれている。

Crawl は活発に開発が続いていて、コードの変更が次々と(しばしば毎週、ときには毎日)入ってくる。trunk は、最新の変更を含んだ版のコードだ。こうした変更はときどきまとめられてリリース版になる。リリース版は、バグなどの問題をできるだけ減らすようにテストされている。

Crawl のソースコードは https://github.com/crawl/crawl で見られる。最初に表示されるのは trunk だ。過去のリリース版のソースコードを見るには、"Branch: master" と書かれたドロップダウンを押して "tags" を選び、見たい版を選ぶ。

コードの中を検索するには、ページの上にある入力欄に検索したい言葉を入れる。検索は大文字と小文字を区別せず、trunk の版しか探さないことに注意。

開発に加わりたい人は、貢献の手引きとCrawl の開発 wiki の入門ページを読んでおくといい。そうでない人も、ソースダイブでゲームの秘密をあれこれ探り出すのを楽しめるだろう。

ソースダイブ

「ソースダイブ」とは、プログラムのソースコードを読んだり検索したりすることだ。ゲームの中で何かが本当はどう動いているのかを知りたいときに、ソースダイブすることが多い。ソースダイブをする人の中には、ゲームのパッチを自分で書く人もいる。

C++ がわからない人でも、ソースダイブすれば、ソースの中のイースターエッグやおもしろいコメントを見つけたり、基本的なデータや文章(ゲーム内の雰囲気づけのメッセージなど)を調べたりできるかもしれない。
