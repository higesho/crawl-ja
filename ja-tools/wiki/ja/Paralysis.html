あなたは麻痺しており、まったく行動できない。

麻痺は、プレイヤーやモンスターがしばらくの間、移動も行動もできなくなる状態異常だ。

効果

麻痺している間は次のようになる。

  • 何も行動できない。
  • EV がほぼ 0 になる。プレイヤーは 2 + size_factor、モンスターは EV 0 になる。
  • SH が 0 になる。
  • モンスターは上位の急所攻撃を受けやすくなる。

麻痺が解けると、プレイヤーは 1〜3 ターンの間朦朧への耐性を得て、麻痺とほかのいくつかの状態異常を受けなくなる。石化と違って、ダメージが軽減される特別な効果はない。

フォーミシッドは停滞の性質のおかげで麻痺しない。また、完全に石化したプレイヤーも麻痺しない。

原因

麻痺の原因はいくつかある。抵抗できるものもあれば、できないものもある。

100% 防ぎきることもできる麻痺の原因:

  • 麻痺の呪文(金縛りのワンドも含む)。プレイヤーなら 2〜5 ターン。対象の意志力を上回る必要がある。
  • 巨大赤色蜂や女郎蜘蛛の近接攻撃(1〜3 ターン。毒耐性があれば 2/3 の確率で防げ、毒が効かなければ麻痺しない)。
  • 形なきクラゲの近接攻撃(1 ターン。毒耐性があれば 2/3 の確率で防げ、毒が効かなければ麻痺しない)。

それ以外の原因は、フォーミシッドでなければ抵抗できない。

  • 気絶の炸裂(1 ターン。電撃耐性があれば 50% の確率で抵抗できる)
  • 5 体以上が視界にいるときの呪われし群れの金切り声(1〜2 ターン)
  • ゾットの罠(2〜5 ターン)
  • ウスカヤーやジンの怒り(2〜5 ターン)
  • 死のとば口をボーグンジョルの究極治癒で打ち消したとき(2〜5 ターン)

戦略

モンスターによる麻痺が 1 ターンより長く続くことがあるなら、それは即死だと考えるべきだ。たいていのモンスターは、4〜5 ターンもただで殴らせてもらえばあなたを殺せる。相手が何体もいれば、4〜5 ターンあれば確実に殺される。1 ターンだけでも、大きなダメージをまとめて受けることがある。EV と SH が 0 になるのはおまけのようなもので、AC が高いプレイヤーにとっても麻痺は厄介だ。

基本的には、麻痺はできる限り避けるべきだ。連勝を狙うプレイなら、即死の確率が 1% 未満でも高すぎる。

小技

麻痺の原因の多くは、何かしらの方法で対処できる。

  • 麻痺の呪文は射線が通っていないと使えない。モンスターが静寂状態や浸水状態なら、呪文は唱えられない。意志力でも防げるが、成功率を 0% にするには高い意志力が必要だ。麻痺の確率を 0% にしたいなら、種族の意志力が重要になる。
  • 巨大赤色蜂は速い敵で、近接攻撃で麻痺させてくる。毒耐性があれば麻痺に抵抗できることがあるが、確実に防げるのは毒が効かない場合だけだ。発動を少し鍛えておけば、ワンドで巨大赤色蜂を倒したり変化させたりできることが多い。樹木化すれば、樹化の rPois と上がった AC のおかげで、巨大赤色蜂1匹に殺されることはまずなくなる。
  • 女郎蜘蛛も、近接攻撃で麻痺させてくる速い敵だ。近接攻撃のしくみは巨大赤色蜂と同じだが、女郎蜘蛛は防御も意志力もずっと高く、そのうえ危険な遠距離攻撃の呪文もいくつか持っている。
  • 大気の精霊の麻痺は 1 ターンだけだが、危険な敵が何体も攻撃してくる場所では命取りになりうる。回避は高いが比較的打たれ弱いので、強力で決して外れない攻撃で狙うとよい(たとえばリーの瞬間解体術、旋風の一撃、発動のスキルが高いときの吹雪のワンドなど。震動石の缶は外れることもあるが、命中率はとても高い)。
  • ゾットの罠は、あなたかモンスターが踏まないと作動せず、しかも罠があなたの視界に入っていないと働かない。ゾットの罠にはほかにも厄介な効果がいくつもあるので、できる限り避けるべきだ。

変更履歴

  • 0.33 より前は、麻痺のあとに得られるのは朦朧への耐性ではなく、麻痺への耐性だけだった。また、能力値が 0 になると麻痺した。
  • 0.29 より前は、麻痺の呪文と神の怒りによる麻痺は 2〜7 ターン続いた。
  • 0.27 より前は、バーサークが切れたあとにプレイヤーが麻痺することがあり、トログと発作的バーサークはどちらもそれを防いでいた。
  • 0.25 より前は、呪術のひどい呪文失敗の効果でプレイヤーが麻痺することがあった。
  • 0.24 より前は、麻痺の吹き矢針があった。
  • 0.18 より前は、停滞の護符で麻痺を防げた。
