操作

  • c を押すと装備を外すメニューが出て、武器、防具、装身具を外せる。
  • C を押すと、隣の扉を閉める。開いた扉が隣にいくつもあるときは、どれを閉めるか聞かれる。

コンソール

コンソール版では次のようになる。

  • c はセントール、ヤクトール、サテュロス系のモンスターを表す。
  • C はさまざまな巨人系のモンスターを表す。

  • 0.26 より前は、c を押すと死体を解体した。
