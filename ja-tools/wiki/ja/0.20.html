この記事は Crawl の過去のリリースについてのものだ。最新版を含むほかのバージョンについては、Stone Soup のバージョンの一覧を参照。

0.20 は Dungeon Crawl Stone Soup のバージョンの一つで、2017年5月25日にリリースされた。

主な変更

  • 新しい種族: バラチ
  • 新しい呪文: 有毒の蒸気と点火
  • 新しいアイテムスカーフ: クロークの枠につける防具で、新しいエゴを持つ
  • 新しい発動アイテム: ワンドと、以前はロッドにあった呪文をもとにした発動アイテム


分岐・環境

  • ロイヤルジェリーが死ぬと、スライムの穴ぐらの宝物庫のヴォールトの壁が崩れるようになった。
  • ゲーム中に(飛びつき蜘蛛などが)作った蜘蛛の巣の罠は、抜け出すと壊れるようになった。
  • 太古の霊廟では、階段の代わりに一方通行の脱出ハッチが置かれ、その近くに戻るためのハッチがあるようになった。
  • 新しいダンジョンの地形、転送装置: 同じ階の別の場所へ行ける一方通行のポータル。今は、新しく加わったいくつかの宝のヴォールトで使われている。


キャラクター

  • 新しい種族: バラチ。生まれつき強力な蛙跳びの能力を持ち、適性もよい。その代わり移動が遅いが、基本の視界の半径が広い。
  • オーガの適性が調整され、メイスと連接棍のスキルの代わりに呪文が得意になった。
  • ミイラの呪文詠唱の適性が -1 から +2 に上がった。
  • 闇ドワーフは、自分を回復する代わりに一定の確率で最大 MP が永久に減る能力を生まれつき持つようになった。以前の充填の能力は削除された。
  • 大きな騒音で、魅了や恐慌が解けなくなった。
  • さまざまな「不利な変身」(霧化など)の特別扱いが削除された。
  • 疲労を引き起こしていたいくつかの能力は、それぞれ専用の待ち時間を持つようになった。
  • 削除:
    • ハイエルフ。
    • 斑紋ドラコニアン。
    • 名残だけ残っていた溶岩オークとジンニー。セーブデータは読み込めるが、(確認のあと)丘オークと歩き蔓に変わる。


神

  • 輝けるもの:
    • 浄化の炎が、邪悪でない敵によく効くようになった。
    • 追加ダメージを与える「急所攻撃」が、どれもできなくなった。
    • 毒が禁じられなくなった。
  • エリヴィロンの怒りの効果のうち、軽いものが削除された。敵の救命が強くなった。
  • ネメレクスの怒りは、カードの山に細工するのではなく、すべてのカードの山を取り上げるようになった。


インターフェース

  • 種族の選択メニューが作り直され、考え方に沿ってわかりやすく並ぶようになった。種族は「初級」「中級」「上級」に分けられている。
  • 右上に、金貨の代わりに直前のターンの騒音が表示されるようになった(金貨は % と $ で今も見られる)。
  • 端末の色が、標準の設定でより多くの端末で正しく出るようになった。ただしその影響で、地図の背景色の標準が暗い青になった。暗い灰色にするには、端末に応じて rc ファイルで `bold_brightens_foreground=true` か `allow_extended_colours=true` を設定する。
  • 新しい equip_bar オプション。騒音の表示の代わりに、身につけているアイテムの記号を表示する(コンソール版のみ)。
  • モンスターの説明に、そのモンスターの近接攻撃が、受けうるダメージの見積もりとともに載るようになった。
  • 近接攻撃で相手を混乱させる攻撃の、成功する見込みが表示されるようになった。
  • auto_butcher を、空腹の段階ごとに働くよう設定できるようになった。
  • アイテムの記録の検索で、ありふれた武器・防具・矢弾が遠くに重複して見つかっても、標準では隠すようになった。検索結果は、冠詞などを含む文字列全体ではなく、まずアイテムの説明の名前で並べられるようになった。
  • 赤で表していた衰弱が、赤とマゼンタに分かれた。マゼンタがいちばん重い。
  • WebTiles でマウスが使えるようになった(今は標準で有効。以前は隠しオプションだった)。
  • ローカル版で、好きな効果音を使う仕組みが大きく改善された。くわしくは https://github.com/crawl/crawl/commit/4270d38ebf63 を参照。
  • SDL 版のタイル版が、スクリーンセーバーを止めなくなった。


アイテム

  • 新しい種類のアイテム: スカーフ。クロークの枠を使う。
    • スカーフは AC が 0 で強化できないが、必ずエゴを持つ。
    • スカーフのエゴ: 雲無効、精霊の盾、耐性、rMsl。
  • 発動アイテム:
    • 新しい種類のワンド: 雲のワンドと散弾のワンド。
    • 新しい道具: 稲妻のロッド。チャージが 4 回で、経験値で充填される発動アイテム。
    • ワンドが、発動スキルでよりよく強くなるようになった。
    • 混乱しているときはワンドを振れなくなった。
    • 分解のワンドが地形を壊さなくなった。
    • 掘削のワンドで彫像を壊せるようになった。
    • ワンドと道具の獲得は、「発動アイテム」にまとめられた。
  • 固定アーティファクト:
    • 新しい固定アーティファクト: マクスウェルの熱機関。冷気と火炎のダブルソードで、振るうたびに力が増していく。
    • 鼠の毛皮のクロークの性能が調整され、ネズミを召喚できるようになった。
    • 血に飢えた首飾り: 殺戮+6(以前は +3)、MR++(以前は MR+)。
    • 無知の大盾: +10 {Int-4, rN+} になった。*Curse と AC+4 は削除された。
    • 聖戦の剣: 狂信者の剣に名前が変わった。
    • 苦悩の王笏は、ランダムにではなく、攻撃が当たったときにだけ拷問を起こすようになった。
    • 船長のカトラスで、ヒドラの首を切り落とせなくなった。
    • 少林寺の指輪は位相の指輪に、クリシュナの弓『シャーランガ』はロングボウ『ゼファー』に名前が変わった。
  • 突然変異治療の薬、良性突然変異の薬、突然変異の薬が一つにまとめられた。
  • どの食料も、食べるのにかかるのは 1 ターンになった。
  • どの種類の虎の巻も、はじめから識別されているようになった。
  • 武器:
    • 釘つき巨大棍棒の基本の攻撃時間が少し短くなった。
  • 削除:
    • 癒しのワンド、加速、テレポート、減速のワンド。
    • ロッド。
    • 嵐の円盤。
    • 最高会議の帽子、燃えさかる死のシミター、冷たき死の短刀。
    • ビーフジャーキーとピザ。

モンスター

  • ドラコニアンの召喚師 -> 嵐招き。打擲の一撃、ドレイクの召喚、自然の怒りを使う。
  • まだらのドラゴン -> アシッドドラゴン。
  • 双頭のオーガがかなり強くなった。
  • 「衰弱」の効果で、モンスターの MR がふたたび下がるようになった。
  • いくつかのユニークモンスターを倒したときの見返りが大きくなった。
  • アリゲーターなどのモンスターが疾走の能力を使ったときの、移動速度の上がり方が大きくなった。
  • モーリスとイジェィブは、必ずワンドを持つようになった。また、イジェィブが初めて出る階が、迷宮の少し深いところになった。
  • ドラコニアンのプレイヤーの幽霊が、負のエネルギーのブレスを持たなくなった。
  • 削除:
    • 斑紋ドラコニアン。
    • ドラコニアンの狂信者。
    • 丘の巨人。


呪文

  • 新しい呪文: 有毒の蒸気(L2 毒の魔術/風の魔術)。狙った相手の上に、ごく短い間だけ続く毒の雲を作る。毒素の魔術師の魔法書に入っている。
  • 新しい呪文: 点火(L8 炎の魔術)。視界にいるすべてのモンスターに、弱めたファイアボールを落とす。術者とその従者は巻き込まれない。
  • ゲルの引力は転位術だけの呪文になった(以前は転位術/呪術)。
  • 射出物の転送は転位術/呪術の呪文になった(以前は転位術だけ)。
  • 転位術師と神秘の射撃手の初期の魔法書で、射出物の転送とゲルの引力が入れ替わった。
  • 妖術の魔法書: 戦闘球が力場の槍に置き換わった。
  • 大気の魔法書: 飛び道具反発が旋風の一撃に置き換わった。
  • 混乱の一撃が、特に HD の高い敵に効きにくくなった。
  • 砂の突風は、所持品の石を直接消費するようになった。その代わり、弾がないと使えなくなり、大岩も消費できなくなった。
  • 削除:
    • 遅延式ファイアボール。
    • 猛毒の雲。
    • 飛び道具反発。
