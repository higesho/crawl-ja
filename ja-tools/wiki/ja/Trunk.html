trunk 限定: この記事は、テスト中の Crawl の機能を扱っている。次のリリースまでに変わる可能性が高く、まるごと削除されることさえある。


安定版と安定版のあいだ、Crawl の開発の大部分は trunk で進む。誰でも手に入る trunk のビルドを使えば、新しい要素やバランスの変更、バグ修正を先取りして遊び、試すことができる。ただし実験的なコードの変更が(深刻なものも含めて)バグを生むこともある。もっと実験的なコードのブランチとは違い、trunk の変更のうち開発者とプレイヤーの支持を得たものは、たいてい次の安定版に入る。

変更は次の場所で追いかけられる。

  • バージョンごとの開発のまとめ
  • Git のコミット

今後の開発について話し合ったり、読んだりできる場所:

  • The Tavern(公式フォーラム)
  • CDO にある古い開発 wiki - 登録は停止中
  • GitHub の開発 wiki
  • 昔の開発メーリングリストのアーカイブ。
  • IRC: Libera の #crawl と #crawl-dev
