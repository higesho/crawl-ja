# 英語版 wiki の記事の訳し方

`work/src/<名前>.html`(英語の本文)を訳して `ja/<名前>.html` に書く(訳は Git で管理する)。
`work/gloss/<名前>.tsv` は、その記事に出てくるゲームの用語の「英語<TAB>日本語版での訳語」。

## 訳語

- ゲームの用語(モンスター・アイテム・呪文・神・種族・職業・スキル・分岐・変異・状態など)は、
  **必ず日本語版のゲームの訳語を使う**。まず `terms_wiki.tsv`(全記事で揃える訳。最優先)、
  次に `gloss` の表を見る。`terms_wiki.tsv` には `ja-tools/CONVENTIONS.md` の
  「揺れやすい用語」(branch は分岐、mutation は変異、skill はスキル など)が入っている。
- 表に無い用語は、ゲームの辞書を英語で検索して訳語を探す:
  `crawl-ref/source/dat/database/ja/jtrans/*.txt`(`%%%%` の次の行が英語、空行のあとが訳)と、
  `crawl-ref/source/dat/descript/ja/*.txt`。見つからないときだけ自分で訳し、
  記事の最初に出たところで英語を括弧で添える(例: 「呪文の成功率(spell success)」)。
- 用語表は自動で作っているので、同じ英語に意味の違う訳が当たることがある。文脈で選ぶ。
  例: Armour は スキルなら「甲冑」、装備品なら「防具」。Smite は呪文名なら「打擲の一撃」。
  呪文名・モンスター名など、何を指すかがはっきりしているときは、そちらの訳を優先する。
- 複数形・所有格でも同じ訳語にする(Ugly things → 醜きもの)。
- 固有の数値、式、キーの名前(`a`、`Ctrl-F` など)、英語のままのコマンド名は変えない。
- 能力値などの略語(AC、EV、SH、HP、MP、XL)はそのまま。

## 文体

- だ・である調。日本語の攻略 wiki として自然に読める文にする。
- 機械的な訳や、AI が書いたような言い回しを避ける。たとえば:
  - 「——」で文をつなぐ、箇条書きの頭に太字のラベルを置いて「——」で説明を続ける
  - 括弧の多用、「〜することができる」の連発、「〜である。〜である。」の単調な繰り返し
  - 英語の語順をなぞった長い修飾
- 原文の内容は足さない・削らない。冗談や軽い口調は、日本語の軽い口調で残す。
- 引用(神の言葉など)はゲームの訳があればそれを使う(`descript/ja/quotes.txt`、`database/ja/godspeak.txt` など)。

## HTML

- タグと属性は**そのまま**残す。訳すのは文字の部分だけ。
- `href`、`id`、`class`、`src` は変えない(見出しの `id` は目次のリンク先)。`title` 属性と `alt` は変えない。
- 表の中の数値や記号もそのまま。
- 書き出しは UTF-8。ファイルの頭に何も足さない(本文の HTML の断片のまま)。

## 自分で訳した用語の記録

用語表にも辞書にも無くて自分で決めた訳は、`work/new_terms/<名前>.tsv` に「英語<TAB>訳」で一行ずつ書き出す
(ほかの記事と訳を揃えるため。まとめて `terms_wiki.tsv` に取り込む)。
訳す前に `terms_wiki.tsv` と、すでにある `work/new_terms/*.tsv` を見て、同じ語は同じ訳にする。

## 記事の題

記事の題(英語)の訳を `titles/<ファイル名の幹>.txt` に書く。1 行目に英語の題、2 行目に訳。
題がゲームの用語(モンスター名・呪文名など)ならゲームの訳語にする。
