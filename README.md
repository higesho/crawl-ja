# Dungeon Crawl Stone Soup 日本語版(0.34)

[Dungeon Crawl Stone Soup](https://github.com/crawl/crawl)(DCSS)の 0.34 を日本語で遊べるようにしたフォークです。作業はブランチ `ja-0.34` で進めています。本家の英語の説明は [README.en.md](README.en.md) に残してあります。

DCSS の日本語化には、dplusplus さんによる 0.16 と 0.19 の日本語版([dcss-0.19-ja](https://github.com/dplusplus/dcss-0.19-ja) など)がありました。ただ 0.19 からは本家のソースがかなり変わっているので、0.19-ja を順にマージしていくのはあきらめ、0.34 の安定版(0.34.1)に翻訳の仕組みを移し直す形を取りました。0.19-ja の辞書と訳文は使えるところはそのまま使わせてもらい、足りない分を訳し足しています。用語もなるべく 0.19-ja に合わせました。

## 訳してあるもの

ゲーム中に出る文章はほぼすべて日本語になります。メッセージ、メニュー、アイテム・モンスター・呪文・神の名前と説明、モンスターの台詞、チュートリアル、ゲーム内のヘルプ(マニュアル、オプションの説明、適性表など)、0.34 の更新履歴まで訳しました。

英語のまま残しているのは、本や詩から採った引用文の一部(465 件中 182 件)と、デバッグ用の表示、ウィザードモードの内部名などです。アイテム説明の検索に使う接頭語も英語のままにしてあります。

## 遊び方

Windows 用のタイル版を[リリース](https://github.com/higesho/crawl-ja/releases)に置いています。`stone_soup-…-tiles-win64.zip` を展開して `crawl.exe` を起動すれば日本語で始まります。

フォントは Windows に標準で入っている BIZ UDゴシックを使います(Windows 10 は 2018年10月の更新から入っています)。設定は `settings/init.txt` の先頭にあり、英語に戻したいときやフォントを変えたいときはそこを書き換えてください。

## 対応していないもの

- コンソール版(端末で動く文字だけの版)とウェブタイル版は作っていませんし、試してもいません。
- Linux と macOS でもソースからビルドはできるはずですが、確かめていません。その場合は `settings/init.txt` のフォントの指定を手元のフォントに直す必要があります。
- 公式版のセーブデータとの行き来は試していません。

## ソースからのビルド

本家と同じ手順でビルドできます([INSTALL.md](crawl-ref/INSTALL.md))。Windows では Visual Studio で `crawl-ref/source/MSVC/crawl.vcxproj` を Release Tiles / x64 でビルドしています。日本語化で足した仕組みや作業の手順、用語の決まりは `ja-tools/` にまとめてあります(README.md、CONVENTIONS.md、STATUS.md)。

## 不具合など

訳の間違いや不自然なところ、表示の崩れを見つけたら Issue で知らせてもらえると助かります。原文の英語が分かるとありがたいです。
