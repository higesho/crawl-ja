<h>Examine surroundings ('<w>x</w><h>' in main):\n<w>Esc</w> : cancel (also <w>Space</w>, <w>x</w>)\n<w>Ctrl-X</w> : list all things in view\n<w>Dir.</w>: move cursor in that direction\n<w>.</w> : move to cursor (also <w>Enter</w>, <w>Del</w>)\n<w>g</w> : pick up item at cursor\n<w>v</w> : describe monster under cursor\n<w>+</w> : cycle monsters forward (also <w>=</w>)\n<w>-</w> : cycle monsters backward\n<w>^</w> : cycle through traps\n<w>_</w> : cycle through altars\n<w><<</w>/<w>></w> : cycle through up/down stairs\n<w>Tab</w> : cycle through shops and portals\n<w>r</w> : move cursor to you\n<w>e</w> : create/remove travel exclusion

<h>周辺を調べる (通常時に'<w>x</w><h>'コマンド):
<w>Esc</w> : キャンセル (<w>Space</w>, <w>x</w>も同様)
<w>Ctrl-X</w> : 視界内のものをすべて一覧表示
<w>(方向)</w>: その方向にカーソルを動かす
<w>.</w> : 指定位置に移動 (<w>Enter</w>, <w>Del</w>も同様)
<w>g</w> : 指定位置のアイテムを拾う
<w>v</w> : 指定位置のモンスターの解説を見る
<w>+</w> : モンスターを順に切り替え (<w>=</w>も同様)
<w>-</w> : モンスターを逆順に切り替え
<w>^</w> : 罠を順に切り替え
<w>_</w> : 祭壇を順に切り替え
<w><<</w>/<w>></w> : 上り/下り階段を切り替え
<w>Tab</w> : 商店もしくはポータルを切り替え
<w>r</w> : カーソルをプレイヤーの位置に戻す
<w>e</w> : 立入禁止区域を設定/解除する
%%%%
<h>Targeting (zap wands, cast spells, etc.):\nMost keys from examine surroundings work.\nSome keys fire at the target. <w>Ctrl-X</w> only\nlists eligible targets. By default,\nrange is respected and beams don't stop.\n<w>Enter</w> : fire (<w>Space</w>, <w>Del</w>, <w>f</w>)\n<w>.</w> : fire, stop at target\n<w>@</w> : fire, stop at target, ignore range\n<w>!</w> : fire, don't stop, ignore range\n<w>p</w> : fire at Previous target (also <w>f</w>)\n<w>:</w> : show/hide beam path\n<w>Shift-Dir.</w> : fire straight-line beam\n             (also <w>/ Dir.</w>)\n\n<h>Firing mode ('<w>f</w><h>' in main):\n<w>Q</w> : choose fire action.\n<w>(</w> : cycle to previous suitable action\n<w>)</w> : cycle to next suitable action.

<h>照準 (ワンドを振る、魔法を唱える等):
周辺を調べる時のキーがほとんど使える。
いくつかのキーで標的に向けて発射する。
<w>Ctrl-X</w> は狙える対象だけを一覧表示する。
通常では射程距離が考慮され、ビームは
途中で止まらない。
<w>Enter</w> : 発射 (<w>Space</w>, <w>Del</w>, <w>f</w>)
<w>.</w> : 発射して対象で止まる
<w>@</w> : 発射して対象で止まる(距離を無視)
<w>!</w> : 発射するが止まらない(距離を無視)
<w>p</w> : 前回の標的を狙う (<w>f</w>も同様)
<w>:</w> : 射線を表示/非表示する
<w>Shift-(方向)</w> : 一直線にビームを発射
             (<w>/ (方向)</w>も同様)

<h>射撃モード (通常時に'<w>f</w><h>'コマンド):
<w>Q</w> : 射撃する行動を選ぶ
<w>(</w> : 前の適切な行動に切り替え
<w>)</w> : 次の適切な行動に切り替え
