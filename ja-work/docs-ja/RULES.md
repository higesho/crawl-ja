# ヘルプ文書の翻訳規約

ゲーム内ヘルプ(`?` メニュー)で表示する文書を訳す。原文は `ja-work/docs-en/`、
分担用に切り分けたものが `ja-work/docs-en/parts/`。訳は `ja-work/docs-ja/parts/` に
同じファイル名で書く。訳し終えたら担当の訳を組み合わせて `crawl-ref/docs/ja/` に置く
(組み合わせはまとめ役がやる)。

## 表示のされ方(崩さないために)

- ゲームは文書を「折り返し済みのテキスト」としてそのまま表示する。1 行は表示幅
  **79 桁以内**(全角 2 桁、半角 1 桁)。
- 段落は 1 行に長く書いてよい。書き終えたら
  `python -I ja-tools/docwrap.py <訳のファイル>` で折り返し、
  `python -I ja-tools/docwrap.py --check <訳のファイル>` で問題 0 件にする。
  折り返しの続きの行は元の行の字下げ(と箇条書きの記号の幅)にそろう。
  ただし docwrap は 1 行ずつしか見ないので、**原文で複数行にわたる段落は、訳では
  1 行にまとめてから** docwrap にかける(原文の改行位置に合わせて訳を切らない)。
- **曖昧幅の文字を使わない**(日本語フォントで重なる)。`…` は `...`、`×` は `x`、
  `→` は `->`、`※` `○` `●` `★` `―` `“ ”` `‘ ’` `°` なども使わない。
  docwrap が「曖昧幅の文字」として報告する。
- 構造はすべて原文どおりに残す: 空行、字下げ、`----` の区切り線、表の桁、目次。
- マニュアル(crawl_manual)の節見出しは、区切り線(`-` が 72 個)の直後の行の
  **先頭の英大文字・数字**(`A.` `B.` ... `1.` `2.`)がヘルプの移動キーになる。
  見出し行は `A.` などで始め、その後ろの見出し名を訳す(大文字の英語は
  「概要」のような日本語に)。見出し名は 72 桁の中で中央ぐらいに置く。
  目次の行(`A.      Overview` など)も同じ記号を残して訳す。
- 表(キー一覧、オプションの一覧など)は、表示幅で桁をそろえ直す。
  全角は 2 桁と数える。キーや記号の列はそのまま。

## 訳さないもの

- キー(`Ctrl-F`、`o`、`Shift-方向キー` の `Shift`)、コマンドの文字、記号
- オプション名・値・rc ファイルの書き方の例・Lua のコード・正規表現・ファイル名・
  ディレクトリ名・URL・コマンドライン引数
- 文書の中で英語のまま例として出しているゲーム内の英文で、訳すと例として
  意味が通らなくなるもの(オプションの値に書く英語のメッセージなど)は英語のまま。
  必要なら後ろに(訳)を添える。

## 文体と用語

- 常体(だ・である)。句読点は全角「、。」。括弧は半角の `(` `)` を使う(既存の
  ヘルプ訳 `crawl-ref/source/dat/database/ja/help.txt` と同じ)。
  鉤括弧は「」。
- 用語はゲーム内の訳に合わせる。辞書は `crawl-ref/source/dat/database/ja/jtrans/`
  (種族 `data-species.txt`、職業 `data-jobs.txt`、スキル `data-skills.txt`、
  神 `data-gods.txt`、分岐 `data-branches.txt`、地形 `data-features.txt`、
  呪文 `data-spells.txt`、アイテム `data-items.txt`、変異 `data-mutations.txt`、
  コマンド `command.txt`、メニュー `menu.txt` など)。形式は英文の行の次に訳の行、
  項目の区切りは `%%%%`。`grep -n -i -A2 "^Deep Elf$" <辞書>` のように引く。
  キーと操作の説明は `crawl-ref/source/dat/database/ja/help.txt`(`?` のキー一覧の
  訳)にそろえる。FAQ の訳 `crawl-ref/source/dat/database/ja/FAQ.txt` も参考になる。
- 辞書にない固有名詞はカタカナにし、作業報告に挙げる。
- ステータス名は「体力(HP)」「魔力(MP)」「AC」「回避(EV)」「盾(SH)」
  「意志力(WL)」「腕力(Str)」「知力(Int)」「器用(Dex)」など、ゲーム画面の表記に
  合わせる(画面の表記は `jtrans/output.txt` や `data-*.txt` で確かめる)。
