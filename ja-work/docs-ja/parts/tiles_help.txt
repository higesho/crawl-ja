注意: タイル版のDungeon Crawl Stone Soupで動作がひどく遅くなったり、もたついた
りする場合は、このファイルの最後まで読み進めてほしい。


タイル版の操作
--------------

まわりとやりとりする方法はいくつもあり、コマンドのキーを打つことも、マウスを使
うこともできる。

特に注目してほしいのは、画面の右にあるクリックできるタブの領域で、ここから所持
品、呪文、よく使うコマンドなどを手軽に使える。

画面の解像度によって、これらのパネルのうちいつでも1つ以上が開いているが、タブの
アイコンをクリックすれば、所持品の表示を一時的に別の種類のタイルのパネルと入れ
替えられる。

コントロールパネルの優先順位は、settings ディレクトリにある init.txt の
tile_layout_priority オプションを変えて調整できる。


移動
----

矢印キー、viキー、テンキーで移動できる。(テンキーはNumlockのオンとオフの両方を
試してみよう。)

テンキー: 7 8 9     viキー:    y k u
           \|/                  \|/
          4-.-6                h-.-l
           /|\                  /|\
          1 2 3                b j n


同じ方向に何歩も走るには、これらのキーと一緒にShiftを押す。

マップかミニマップのどこかをマウスでクリックしても移動できる。そのマスに今の位
置からたどり着けて、視界に敵対的なモンスターがいなければ、そこまで自動で移動す
る。視界に敵対的なモンスターがいる場合は、1回に1歩ずつしか進まない。

自動探索をするには、'o'コマンドを打つか、画面の右にあるコマンドパネルの対応する
タイルをクリックする。クリックでの移動と同じく、視界に敵対的なモンスターがいる
と、これらは働かない。


情報を得る
----------

メインのマップやタイルのコントロールパネルにある地形、モンスター、アイテムをマ
ウスで右クリックすると、その地形、モンスター、アイテムの説明が別の画面に表示さ
れる。

マウスを重ねるだけでも、たいていはメッセージ欄に同じ説明(または収まる分だけ)が
表示される。

同じように、地形、モンスター、アイテムの上にしばらくマウスを置いておくと、たい
ていは使えるコマンドの「ツールチップ」が表示される。


モンスターへの攻撃
------------------

移動キーでモンスターに向かって移動するか、マウスでモンスターをクリックすると、
そのモンスターに近接攻撃ができる。

遠隔攻撃(呪文やワンドも含む)をするには、モンスターにマウスを重ね、ツールチップ
が出るのを待つ。または、呪文パネルの呪文のタイルをクリックして呪文を唱えたり、
所持品パネルの矢弾やワンドをクリックして撃ったり発動したりもできる。

コマンドパネルには「自動戦闘」と説明されたタイルもある。これをクリックすると、
隣にモンスターがいれば近接攻撃し、隣にモンスターがいなければ一番近いモンスター
の方向へ1歩進む。


アイテムの使用
--------------

アイテムを使ういちばん簡単な方法は、所持品パネルでアイテムをクリックすること
だ。マウスを重ねたときのツールチップには、クリックで何が起きるかと、同じ操作を
するためのコマンドキーも表示される。
または、所持品一覧('i'コマンド)でアイテムを選び、操作のプロンプトで該当するキー
を押してもアイテムを使える。

床にあるアイテムを拾うには、所持品パネルの床の欄でアイテムを1つずつクリックする
か、プレイヤーのタイルをクリックして、選べるアイテムのメニューを出す。後者の場
合は、'Enter'で選択を確定すると拾い始める。

アイテムを置くのも同じようにできる。所持品パネルでアイテムを1つずつクリックする
か、'd'コマンドを打ってメニューからアイテムを選ぶ。


ダンジョンとのやりとり
----------------------

ここでも、メインのマップで地形(階段や扉など)にマウスを重ねると、それとどうやり
とりすればよいかが表示される。


キャラクターの状態
------------------

プレイヤーのタイルを右クリックすると、装備、耐性、能力値を一覧にしたキャラク
ターの概要の画面が表示される。

キャラクターの特定の面についてのもっと詳しい画面は、コマンドパネルの対応するタ
イルをクリックすると開ける。


キャラクターの見た目
--------------------

キャラクターの見た目は、'-'コマンドで開くプレイヤータイル編集(Doll Editor)で変
えられる。'm'でモードを切り替える: 「装備」では、身につけたアイテムに合わせて見
た目が変わる。「デフォルト」は、キャラクターの種族と職業に基づくスプライトだ。
「カスタム」では、キャラクターの見た目の各部分を自由に変えられる。数字キーでカ
スタムの組み合わせを切り替え、矢印キーで各カスタムスプライトのいろいろなパーツ
を変える。変更と選択は'Ctrl-S'で保存する。



動作がひどく遅くなったり、もたついたりする場合...
-------------------------------------------------

CrawlはOpenGLとSDLを使ってグラフィックを描画する。ただし、遅くならずに動くには
ハードウェアアクセラレーションが必要だ。Windowsを使っているなら、グラフィック
カードのドライバーを更新しよう。Linuxを使っているなら、DRIを使っているか確かめ
よう。

i865ほど古いカードでも問題なく動くことが確かめられている。残念ながら、i810では
遅いことが知られており、その場合はコンソール版を使うか、別のマシンに替えるくら
いしか手がない。

settings ディレクトリにある init.txt のいくつかのオプションを調整して、性能がよ
くなるか試してみるとよい:

travel_delay = -1
    この設定にすると、自動移動が終わるか中断されるまで画面を描き直さない。

tile_update_rate = 1000
    初期設定では、画面は少なくとも1000ミリ秒ごとに描き直され、表示が変わる行動
    をとるとそれより頻繁に描き直される。この値を大きくしてみてもよいが、そうす
    ると更新に時間がかかりすぎるかもしれない。

tile_runrest_rate = 17
    走っている間と休憩している間は、画面は17ミリ秒ごとに描き直される。走ったり
    休憩したりしているときにCrawlが遅いなら、この数を増やす。

tile_tooltip_ms = 0
    ツールチップを切れば、毎回描くものが減る。

clear_map = false
    視界の外にいる、覚えているモンスターを描き直さずに済むので、描き直しの処理
    の負担が少し減る。

tile_window_width   = 1024
tile_window_height  = 768
    マップの領域が大きいほど、毎ターン描き直すマスが多くなる。マップに必要な
    17x17マスよりずっと多くを映す大きなディスプレイを使っているなら、もっと低い
    解像度を指定してみるとよい。
